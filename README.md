# JobTrackr - Frontend
React 18 + Vite, React Router, Axios, Recharts, Lucide icons.

    npm install
    cp .env.example .env     # backend URL
    npm run dev              # http://localhost:5173

Pages: Landing, Login/Register, Dashboard, Applications (List + Kanban), Application Detail (AI tabs), Resume, Settings, Admin, 404.
Backend (Spring Boot) must run on http://localhost:8080.
